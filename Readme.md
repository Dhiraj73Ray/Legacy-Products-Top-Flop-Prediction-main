# Product Success Predictor (Legacy)

## What this does
Predicts if a product will be a "Top" or "Flop" based on:
- Category
- Main promotion type
- Color
- Star rating

## Tech Stack
- Python with scikit-learn
- Random Forest (best performer with 82.9% accuracy)
- ANN (Keras) and Logistic Regression for comparison

## Why it's archived
This was built before the ML engineering best practices were implemented.
For the updated version, see [link to new repo].
